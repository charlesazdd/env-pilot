# Contributing

Install stable Rust and Xcode Command Line Tools, then open the project in RustRover or run `cargo run`. Report reproducible bugs and feature requests through GitHub Issues. Submit a focused pull request describing the change and its validation. Use descriptive commits (for example `feat: add setting`). Follow rustfmt and Clippy, and run `cargo fmt --all -- --check`, `cargo clippy --all-targets --all-features -- -D warnings`, and `cargo test --all-targets` before submitting.
